# UNP_REGRESSION

I, along with my team, did this project in collaboration with UNP, where the primary objective was to analyze industrial electricity consumption data from a real steel manufacturing plant — DAEWOO Steel Co. Ltd, South Korea — and derive meaningful business insights using Python. This project focuses on understanding energy usage patterns, load behavior, and efficiency trends within a 24/7 manufacturing environment. The dataset includes key attributes such as usage in kWh, reactive power, power factor, load type, day of week, and time-based fields, spanning a full year of 15-minute interval readings. Using Python (Pandas, Matplotlib, Seaborn, and Scikit-learn), I cleaned and explored the data, ran statistical tests to confirm which patterns were genuinely significant, and built regression models to evaluate how predictable electricity usage actually is. The analysis highlights findings such as the true energy share of each load type, the weekday-versus-weekend consumption gap, seasonal usage peaks, and a fixable power-factor inefficiency in background equipment. I also built two separate models — one using live electrical readings for real-time monitoring, and a second using only calendar information for advance planning — and validated both through train-test splits and cross-validation. Overall, this project shows how raw industrial sensor data can be turned into actionable insights that support maintenance planning, cost reduction, and emissions reporting for a manufacturing plant.
